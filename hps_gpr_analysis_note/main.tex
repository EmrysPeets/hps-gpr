\begin{abstract}
This note documents the Heavy Photon Search (HPS) Gaussian-process-regression (GPR)
workflow for a narrow prompt
$A^\prime \rightarrow e^+e^-$ resonance in the HPS invariant-mass spectrum. The
analysis performs global background interpolation, local signal extraction with
Gaussian-constrained nuisance parameters for the correlated background uncertainty,
modified-frequentist
\CLs\ ($\mathrm{CL}_{s+b}/\mathrm{CL}_b$) upper limits in signal-yield and
$\eps^2$ space, and a statistically independent multi-dataset combination in a shared
$\eps^2$ parameter of interest. The signal model is implemented as a full-range
Gaussian template whose blinded-bin slice enters the local likelihood without
renormalization, so the fitted amplitude retains the interpretation of a total local
signal yield. The note also summarizes the radiative-fraction normalization,
length-scale parameterization, toy-validation program, and staged path from the
published 2015 and 2016 HPS prompt searches toward a fully unblinded combination.
Version 3 uses the regenerated high-$p_{\mathrm{sum}}$ 2021 input, dataset-dependent
length-scale bounds, and a pre-unblinding 90\% CL upper-limit candidate obtained with
\CLs{}. Plotting-export discrepancies are documented explicitly and must be resolved
before a final observed result is claimed.
\end{abstract}
