# HPS GPR Analysis Note v5.0.5

The complete revised note is [HPS_GPR_Analysis_Note_v5p0p5.pdf](HPS_GPR_Analysis_Note_v5p0p5.pdf), 252 pages.

[Source and results](HPS_GPR_v5p0p5_Source_and_Results.zip) include the LaTeX source, figure inputs, saved results, reproduction scripts and compact QA records. After extraction, run `bash scripts/build_note.sh` from the package directory. See its README for software requirements.

This delivery includes the requested wording changes within v5.0.5: dataset terminology, the Results heading, an explanation of LCDD, and detailed toy counts moved to Appendix B. Numerical results are unchanged by this editorial pass.

The original v5.0.5 revision updates Section 1.1 and Figures 1–2, adds campaign geometry to Section 3, adds full-2021 conditional projections after the results, and adds the 1% projections, geometry methods and selected beam-energy studies to the appendices. Equations and study qualifications are retained.

The new bounded binning check finds that the combined fitted signal changes sign at 76 or 77 MeV, depending on the bin widths and origins. It does not recalibrate the global significance.
